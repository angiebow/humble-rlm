# Paper

- Format: ACM SAC 2027 proceedings template (author kit on the SAC 2027 site).
- Length: up to 8 pages with standard registration (max 10 with paid extra pages).
  Under 4 full pages risks desk rejection.
- Review is **double-blind**: no names, affiliations, acknowledgements, or links to this
  repository in the PDF. If reviewers need code, use an anonymized mirror
  (e.g. anonymous.4open.science) and cite it as "anonymized repository".

Copy final figures from `results/figures/` into `figures/` and final CSVs into `tables/`
only once results are locked, so the paper never cites a number that later changed.

Section owners: see `docs/PLAN.md`.
